## Final Task / UrbanCart Solution

Designed and built an end-to-end automation system for **UrbanCart**, an e-commerce company in Pakistan.

The system handles:
- 24/7 customer support through chat and voice
- Product, shipping, return, and warranty questions using RAG
- Lead collection for the sales team
- Basic order status inquiries
- Human escalation for complaints and complex issues
- Slack alerts only for important events

### Task 1 – Analyze & Propose the Solution
Analyzed the client meeting and designed the architecture, data flow, customer journeys, and human-in-the-loop process.

### Task 2 – Build the Proposed Solution
Implemented the working system using:
- **Vapi** for the voice agent
- **n8n** for workflow orchestration
- **Zapier** for business integrations
- **Airtable** for operational records
- **PostgreSQL** for structured data
- **Supabase** for backend and vector search
- **Google Drive** for policy and product documents
- **Notion** for internal documentation
- **Slack** for team notifications
- **RAG** for grounded answers from UrbanCart documents
