# Task 03 – AI Customer Support Bot (CloudFlow)

## Task Description
Build an AI chatbot for a fictional software company called CloudFlow that can answer common customer questions and create support tickets when needed.

The chatbot:
- Answers questions about pricing, features, support hours, and refund policy
- Does not invent information
- Collects customer details when a support request is needed
- Creates a ticket in Zapier Tables
- Automatically assigns Priority (Critical / High / Medium / Low)

## Components
- **Chatbot**: CloudFlow Support Bot
- **Table**: Support Tickets
- **Zap**: Create Support Ticket (triggered by Zap button)
